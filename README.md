# 产品广告分镜与视频技能

将产品参考整理成白底资产，规划生活或棚拍场景、逐镜分镜和提示词，经用户确认后对接已有的视频生成工具。

## 安装到 Codex

1. 解压压缩包，把 `product-asset-storyboard-video` 文件夹复制到 `~/.codex/skills/`。
2. 重新打开或刷新 Codex 会话，然后请求：`使用 $product-asset-storyboard-video 为我的产品制作广告分镜`。
3. 提供有权使用的产品图与创意要求。图片或视频生成能力、账号、费用和联网权限由使用者自己的环境提供。

不同 AI 客户端的安装方式可能不同。技能不会附带 API 密钥、模型账号或视频托管服务。
